CD154 interactive views

Serve this folder over HTTP, or place its contents at the selected GitHub Pages publishing root. index.html uses only bundled viewer/story assets. No build service or CDN is required to view it.

Use the preset menu or Next/Prev to switch views. Drag to rotate and scroll to zoom. On narrow windows the text panel scrolls below the molecule. Close-ups hide context only for display; all structure assets remain complete inside story/protein-2.mvsx.

story/session.mvstory is the editable MolViewStories session. story/protein-2.mvsx is the compiled story. Both represent the same source story. GitHub Pages is the sole sharing location: https://sfreema1.github.io/protein-2-interactive/ . Do not create additional cloud publications or alternative viewer links unless Sebastian asks.

The viewer is official Mol* 5.8.0, exported with the official MolViewStories StoryManager. License files are in licenses/. A WebGL-capable browser is required. Browser restrictions can prevent loading from a file:// page; use HTTP instead.
